# ブランド方向性 - AI成果物判定プロダクト「AI Judge」

## 1. ブランドコンセプト

### 1.1 プロダクトビジョン

> 「AIと人間の協働に、信頼のインターフェースを」

AI Judge は、AIが生成した成果物に対して人間が的確な判断を下すためのプロダクトである。
このプロダクトのブランドは「信頼性」「正確性」「効率性」の3つを柱とし、
AIの力を人間がコントロールできるという安心感を伝えるものでなければならない。

### 1.2 ブランドパーソナリティ

| 特性 | 説明 | 具体的なイメージ |
|------|------|---------------|
| **信頼できる** | 判断の根拠を明確にし、透明性を持つ | 法律事務所の信頼感、医療機器の堅実さ |
| **正確な** | 情報は正確で、曖昧さを排除する | 計測機器の精密さ、地図の正確さ |
| **冷静な** | 感情に流されず、客観的な視点を提供する | ジャーナリズムの中立性 |
| **効率的な** | 無駄がなく、プロフェッショナルの時間を尊重する | 高級工具のシンプルさ |
| **人間中心の** | AIではなく人間の判断を支援するスタンス | コパイロット（副操縦士）の姿勢 |

### 1.3 ブランドステートメント

**タグライン案:**

1. 「判断に、確信を。」 -- 推奨案
2. 「AIの成果を、あなたの基準で。」
3. 「信頼できる判定を、すべての成果物に。」

## 2. ビジュアルアイデンティティ

### 2.1 カラーパレット

#### プライマリカラー

```
Deep Navy    #1E293B  -- 主要背景、ヘッダー、信頼感を表す基調色
Slate Blue   #3B82F6  -- アクセント、リンク、インタラクティブ要素
White        #FFFFFF  -- コンテンツ背景、余白
```

**選定理由:**
- ネイビーは「信頼」「専門性」「安定」を想起させる色であり、
  金融・法律・医療分野で広く使われている
- 派手さではなく落ち着きで品質を伝える
- テクノロジー企業でありながら、過度にテック感を出さない

#### セマンティックカラー（判定ステータス）

```
Approved     #22C55E (Green 500)   -- 承認・成功
Revision     #F59E0B (Amber 500)   -- 修正指示・注意
Rejected     #EF4444 (Red 500)     -- 却下・エラー
Pending      #9CA3AF (Gray 400)    -- 未判定・待機
Info         #3B82F6 (Blue 500)    -- 情報・通知
```

**選定理由:**
- 信号機と同じ直感的な色彩コードを採用（赤=停止、黄=注意、緑=進行）
- ユニバーサルに通じる色意味を利用し、学習コストを最小化する
- 色覚多様性への配慮として、色だけでなくアイコンとテキストを必ず併用する

### 2.3 ロゴ方針

#### コンセプト

- 天秤（バランス・公正な判定）と盾（信頼・保護）のモチーフを組み合わせる
- 幾何学的でクリーンなフォルムとし、テクノロジーの精密さを表現する
- ネイビー単色で成立するシンプルさを持たせる

#### ロゴ構成

```
[アイコン] + [ロゴタイプ]

アイコン:
  - 天秤を抽象化した幾何学図形
  - 左右対称で安定感を持たせる
  - 最小表示サイズ: 24px x 24px

ロゴタイプ:
  - 「AI Judge」をNoto Sans JP Boldで表記
  - 「AI」部分はSlate Blueで強調
  - 「Judge」部分はDeep Navyで安定感を持たせる
```

#### 使用ルール

- 最小余白: アイコン高さの50%をロゴ周囲に確保する
- 背景色制限: 白・薄いグレー・ネイビーの3種の背景のみ許可する
- 変形・回転・透過は禁止する

### 2.4 アイコノグラフィ

#### アイコンスタイル

- **ライブラリ**: Lucide Icons を基本採用
- **スタイル**: ラインアイコン（ストローク幅2px統一）
- **サイズ**: 16px / 20px / 24px の3サイズを標準とする

#### 選定理由

- ラインアイコンはクリーンで専門的な印象を与える
- 塗りアイコンに比べて情報密度が低く、長時間作業の疲労を軽減する
- Lucide Icons はオープンソースで、一貫したデザイン言語を持つ

### 2.5 イラストレーション・ビジュアル方針

- **使用場面**: エラー画面、空状態、オンボーディングに限定する
- **スタイル**: 線画ベース、ブランドカラー（ネイビー+ブルー）の2色で構成する
- **トーン**: 過度に親しみやすくせず、プロフェッショナル向けの落ち着いた印象を維持する
- **キャラクター**: 使用しない。判定という業務の性質上、遊び心よりも信頼感を優先する

## 3. トーン & ボイス

### 3.1 UIテキストの原則

| 原則 | 具体例（良い例） | 避ける例 |
|------|---------------|---------|
| 簡潔に伝える | 「承認しました」 | 「この成果物は承認ステータスに更新されました！」 |
| 客観的に記述する | 「AI自信度: 85%」 | 「AIはかなり自信があります！」 |
| ユーザーの判断を尊重する | 「判定を取り消しますか？」 | 「本当にこの判定でいいですか？」 |
| 専門的だが平易に | 「判定基準に沿ってチェックしてください」 | 「評価マトリクスに準拠した判定を実行してください」 |
| 行動を促す | 「次の成果物を確認する」 | 「次へ」 |

### 3.2 メッセージトーン

- **エラー時**: 原因と対処法を冷静に伝える。ユーザーを責めない
  - 良い例: 「判定の保存に失敗しました。ネットワーク接続を確認し、再度お試しください」
  - 悪い例: 「エラーが発生しました！もう一度試してください」
- **成功時**: 簡潔に確認し、次のアクションを提示する
  - 良い例: 「承認しました。残り11件の未判定があります」
- **空状態**: ポジティブなメッセージで安心感を与える
  - 良い例: 「すべての成果物を判定しました。新しい成果物が届いたら通知します」

## 4. デザイン原則（判断基準）

デザイン上の意思決定で迷った場合、以下の優先順位で判断する。

### 優先順位

1. **正確さ > 美しさ**
   - 情報の正確な伝達を常に最優先する。見た目のためにデータを省略しない

2. **効率 > 網羅性**
   - 全情報を表示するより、判定に必要な情報を素早く伝えることを優先する

3. **一貫性 > 個別最適**
   - 画面ごとの個別最適より、プロダクト全体の一貫した体験を優先する

4. **慎重さ > 速さ**
   - 破壊的な操作（却下、一括操作）には確認ステップを設ける

5. **透明性 > シンプルさ**
   - AIの判断根拠は、UIが複雑になっても表示する。ブラックボックスにしない

## 5. 競合との差別化ポイント

| 差別化要素 | AI Judge の方針 |
|-----------|---------------|
| 専門性 | 汎用ツールではなく「AI成果物の判定」に特化したUI |
| 信頼性の演出 | 法律・医療系ソフトウェアに近い堅実なビジュアル |
| 判断支援 | AIの自信度・過去の判定傾向など、判断を支える情報を豊富に提供 |
| 効率性 | キーボードショートカット・バッチ処理で大量判定に対応 |
| 透明性 | すべての判定にコメント・理由が記録され、監査可能 |
