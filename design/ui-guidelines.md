# UI基本方針 - AI成果物判定プロダクト「AI Judge」

## 1. 設計思想

本プロダクトのUIは「正確な判断を、迅速に、疲労なく行える」ことを最上位の目標とする。
AI成果物の判定という業務は反復性が高く、1日に数十件以上処理する場面も想定されるため、
操作効率と認知負荷の低減を徹底的に追求する。

## 2. 操作性の原則

### 2.1 最小クリック原則

- 成果物の確認から判定完了まで、**最大3クリック以内**で完結させる
- 判定ボタン（承認・修正指示・却下）は常に画面内に表示し、スクロール不要とする
- モーダルダイアログの使用は確認系のみに限定し、入力系には使わない

### 2.2 キーボードファースト

| キー | アクション |
|------|----------|
| `A` | 承認（Approve） |
| `R` | 修正指示（Revise） |
| `X` | 却下（reJect） |
| `N` / `J` | 次の成果物へ |
| `P` / `K` | 前の成果物へ |
| `C` | コメント欄にフォーカス |
| `Ctrl+Enter` | 判定を確定 |
| `/` | 検索にフォーカス |
| `?` | ショートカットヘルプ表示 |

- すべての主要操作にキーボードショートカットを割り当てる
- ショートカットはカスタマイズ可能とする
- 画面右下に常時ショートカットヒントを小さく表示（非表示設定可能）

### 2.3 コンテキスト維持

- 画面遷移を最小化し、可能な限りページ内での操作を維持する
- 判定画面から一覧への戻りは、スクロール位置・フィルタ状態を保持する
- サイドパネルやドロワーを活用し、詳細情報は画面遷移なしで表示する

## 3. 情報の見せ方

### 3.1 情報階層

情報を3階層で構造化し、ユーザーの注意を適切に誘導する。

```
第1階層（最重要）: 生成結果そのもの + 判定アクション
第2階層（補助）  : 元の指示（プロンプト）、判定基準チェックリスト
第3階層（参考）  : AI自信度、過去の類似判定、メタデータ
```

- 第1階層は画面の60%以上の面積を占め、最も目立つ位置に配置する
- 第2階層は隣接配置し、視線移動で自然に確認できるようにする
- 第3階層はサイドバーまたは折りたたみセクションに配置する

### 3.2 成果物種別ごとの表示

| 種別 | 表示方法 | 特記事項 |
|------|---------|---------|
| テキスト | 原文のまま表示、差分はハイライト | フォントサイズ調整可能 |
| 画像 | サムネイル+拡大表示、元画像との比較 | ズーム、オーバーレイ比較対応 |
| コード | シンタックスハイライト付きエディタ風表示 | 行番号表示、折りたたみ対応 |
| 構造化データ | テーブル表示+JSON/YAML切替 | 検索・フィルタ付き |
| 複合成果物 | タブ切替で各要素を表示 | 全体俯瞰ビューも提供 |

### 3.3 比較表示

- 左右分割（デフォルト）: 左に指示、右に生成結果
- 上下分割: 画面幅が狭い場合、または長文コンテンツの場合に切替可能
- オーバーレイ表示: 画像比較時に透過度スライダーで重ね合わせ表示
- diff表示: テキスト・コードの修正版との差分をインラインまたはサイドバイサイドで表示

## 4. 判定結果の表示方法

### 4.1 判定ステータスの視覚表現

```
承認（Approved）
  色: グリーン (#22C55E)
  アイコン: チェックマーク (✓)
  ラベル背景: 薄いグリーン

修正指示（Revision Requested）
  色: アンバー (#F59E0B)
  アイコン: 編集マーク (✎)
  ラベル背景: 薄いイエロー

却下（Rejected）
  色: レッド (#EF4444)
  アイコン: クロスマーク (✕)
  ラベル背景: 薄いレッド

未判定（Pending）
  色: グレー (#9CA3AF)
  アイコン: 時計マーク (◷)
  ラベル背景: 薄いグレー
```

- ステータスは色+アイコン+テキストの3重で伝達する（色覚多様性への配慮）
- 一覧画面では左端にステータスカラーバーを表示し、一目でスキャン可能にする

### 4.2 AI自信度の表示

```
高 (80-100%):  ████████████████████ 92%  緑系プログレスバー
中 (50-79%):   ██████████████░░░░░░ 72%  黄系プログレスバー
低 (0-49%):    ████████░░░░░░░░░░░░ 38%  赤系プログレスバー
```

- 数値+プログレスバー+色で直感的に把握可能にする
- 自信度は判定の強制力を持たない「参考情報」であることを明示する
- ツールチップで自信度の算出根拠を簡潔に表示する

### 4.3 判定結果のフィードバック

- 判定ボタン押下後、**300ms以内**にビジュアルフィードバック（色変化+アニメーション）を返す
- 承認時: 成果物カードが緑に一瞬光り、自動で次の未判定に遷移
- 修正指示時: コメント入力欄が展開、送信後に次へ遷移
- 却下時: 確認ダイアログを表示後、送信して次へ遷移
- 全判定にUndoトースト通知を5秒間表示（「判定を取り消す」リンク付き）

## 5. レイアウトシステム

### 5.1 グリッド

- 8pxベースグリッドを採用
- コンテンツエリアは最大幅1440px、中央寄せ
- サイドバー幅: 240px（折りたたみ時: 64px）
- ガター: 24px

### 5.2 スペーシング

| 用途 | サイズ |
|------|-------|
| 要素内パディング | 8px / 12px / 16px |
| セクション間 | 24px / 32px |
| カード間 | 16px |
| ページマージン | 32px（モバイル: 16px） |

### 5.3 タイポグラフィ

| 要素 | フォント | サイズ | ウェイト |
|------|---------|-------|---------|
| ページタイトル | Noto Sans JP | 24px | Bold (700) |
| セクション見出し | Noto Sans JP | 18px | SemiBold (600) |
| 本文 | Noto Sans JP | 14px | Regular (400) |
| 補助テキスト | Noto Sans JP | 12px | Regular (400) |
| コード表示 | JetBrains Mono | 13px | Regular (400) |
| 判定ボタン | Noto Sans JP | 16px | Bold (700) |

## 6. コンポーネント設計方針

### 6.1 共通コンポーネント一覧

- **ボタン**: Primary / Secondary / Danger / Ghost の4バリエーション
- **カード**: 成果物カード、統計カード、アクティビティカード
- **ステータスバッジ**: 判定ステータスを表す色付きラベル
- **プログレスバー**: AI自信度表示用
- **テーブル**: ソート・フィルタ・ページネーション付き
- **パネル**: 左右分割、上下分割、リサイズハンドル付き
- **トースト通知**: 成功/警告/エラー/情報の4種
- **コメント入力**: Markdown対応、プレビュー切替付き

### 6.2 状態管理

すべてのインタラクティブ要素に以下の状態を定義する:

- Default（通常）
- Hover（マウスオーバー）
- Active / Pressed（クリック中）
- Focused（キーボードフォーカス）
- Disabled（無効）
- Loading（読み込み中）

## 7. アニメーション・トランジション

### 7.1 基本方針

- アニメーションは「操作のフィードバック」と「状態変化の理解促進」の2目的に限定する
- 装飾的なアニメーションは原則使わない
- prefers-reduced-motion メディアクエリに対応し、アニメーション無効化を許容する

### 7.2 トランジション仕様

| 対象 | デュレーション | イージング |
|------|-------------|----------|
| ボタンホバー | 150ms | ease-out |
| パネル開閉 | 250ms | ease-in-out |
| ページ遷移 | 200ms | ease-out |
| トースト表示 | 300ms | ease-out |
| 判定フィードバック | 400ms | ease-in-out |

## 8. ダークモード対応

- ライトモード（デフォルト）とダークモードを切替可能にする
- システム設定に連動する自動切替にも対応する
- 両モードで十分なコントラスト比（4.5:1以上）を確保する
- 判定ステータスの色は両モードで視認性を担保する
