# AI生成物判定プロダクト - 利用規約・免責事項のポイント

作成日: 2026-05-05
作成部署: 法務・経理部

---

## 1. 利用規約に含めるべき主要条項

### 1.1 サービスの性質と限界の明示

```
【必須条項】
- 本サービスの判定結果は統計的な推定に基づくものであり、
  100%の精度を保証するものではない
- 判定結果は参考情報として提供するものであり、
  最終的な判断は利用者の責任において行うものとする
- 技術の進歩により判定精度は変動する可能性がある
```

**趣旨:** 判定結果の誤りに起因する訴訟リスクを低減するための最重要条項。

### 1.2 免責事項

```
【免責範囲のポイント】
(1) 判定結果の正確性、完全性、適時性に関する保証の否認
(2) 判定結果に基づく利用者の行為から生じた損害の免責
(3) 第三者が判定結果を利用したことによる損害の免責
(4) 間接損害、逸失利益、特別損害の免責
(5) サービスの中断・停止に関する免責
(6) 損害賠償の上限額の設定（例: 過去12か月の利用料金総額）
```

**注意:** 日本法下では消費者契約法により、消費者向けサービスでは全部免責条項が無効になる場合がある。事業者向け（BtoB）と消費者向け（BtoC）で規約を分ける検討が必要。

### 1.3 禁止事項

```
【禁止行為の例】
- 判定結果のみを根拠とした個人への懲戒・処分
- 判定結果の改ざん、偽造
- 第三者の名誉・信用を毀損する目的での利用
- 大量の自動アクセスによるサービスへの負荷行為
- 逆コンパイル、リバースエンジニアリング
- 判定システムを回避するツールの開発・頒布
- 法令に違反する目的での利用
```

### 1.4 データの取扱い

```
【データ取扱条項のポイント】
- 判定対象として送信されたデータの取扱方針
  - 処理後の削除時期（即時 / 一定期間後）
  - 判定精度向上のための利用可否（オプトイン/オプトアウト）
- データの第三者提供の有無
- 匿名化・統計情報としての利用範囲
- データ所在地（リージョン指定の可否）
```

### 1.5 知的財産権

```
【知的財産条項のポイント】
- 送信データの著作権は利用者に帰属
- 判定結果の利用権は利用者に付与（ただし利用範囲の制限あり）
- サービス自体（アルゴリズム、モデル等）の知的財産権は当社に帰属
```

## 2. プライバシーポリシーに含めるべき事項

### 2.1 必須記載事項（個人情報保護法・GDPR対応）

| 項目 | 記載内容 |
|---|---|
| 事業者情報 | 会社名、住所、連絡先、DPO（GDPR対応時） |
| 取得する情報 | アカウント情報、判定対象データ、利用ログ、Cookie情報等 |
| 利用目的 | 判定サービスの提供、精度向上、利用統計、カスタマーサポート |
| 法的根拠 | 契約の履行、正当な利益、同意（GDPR対応時） |
| 第三者提供 | 提供先の類型（クラウドプロバイダ、決済事業者等） |
| 保存期間 | データ種別ごとの保存期間 |
| ユーザーの権利 | アクセス権、訂正権、削除権、ポータビリティ権、異議申立権 |
| 越境移転 | 移転先国と適切な保護措置（SCC、十分性認定等） |
| Cookie | 使用するCookieの種類と目的、オプトアウト方法 |

### 2.2 特に注意すべき点

- **判定対象データに個人情報が含まれる場合の取扱い**
  - 利用者が送信するテキスト・画像に第三者の個人情報が含まれる可能性がある
  - 利用者に対し、第三者の個人情報を含むデータの送信時の責任を明示
  - 個人情報が含まれるデータの自動検出・警告機能の検討

- **未成年のデータ保護**
  - 教育機関での利用が想定される場合、COPPA（米国）、FERPA（米国）、児童データ保護に関する各国法への対応

## 3. サービスレベルに関する条項（SLA）

BtoB向けには以下のSLA条項を検討:

| 項目 | 推奨内容 |
|---|---|
| 稼働率保証 | 99.5% 以上（月次） |
| 応答時間 | 判定レスポンス: 5秒以内（テキスト）、30秒以内（画像） |
| サポート対応 | 営業日24時間以内の初回応答 |
| 障害時の返金 | SLA未達時の利用料金の一定割合を返金 |
| 判定精度 | 精度指標の定期公開（保証値ではなく目標値として） |
