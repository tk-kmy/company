作成部署: 法務・経理部

## 1. EU AI Act（AI規制法）

### 1.1 概要

EU AI Actは2024年に成立し、2025年から段階的に施行されている世界初の包括的AI規制法。AIシステムをリスクレベル別に分類し、高リスクAIに対して厳格な義務を課す。

### 1.2 本プロダクトの分類

| 分類候補 | 該当可能性 | 根拠 |
|---|---|---|
| 禁止されるAIシステム | 低い | ソーシャルスコアリング等には非該当 |
| 高リスクAIシステム | **可能性あり** | 教育分野での使用（学生の評価に影響）、雇用分野での使用（採用・評価に影響）の場合 |
| 限定リスクAIシステム | **該当する可能性が高い** | 透明性義務が課される |
| 最小リスクAIシステム | 用途次第 | 一般的なツールとしての利用 |

### 1.3 対応すべき義務

#### 透明性義務（全リスクレベル共通）
- AIシステムであることの開示
- 判定の仕組みに関する説明（技術的文書の整備）
- 出力がAIによるものであることの明示

#### 高リスク該当時の追加義務
- リスク管理システムの構築・運用
- データガバナンス（学習データの品質管理・バイアス検査）
- 技術文書の作成・保管
- 自動ログ記録機能の実装
- 人間による監視（Human Oversight）の仕組み
- 精度・堅牢性・サイバーセキュリティの基準適合
- CE適合性評価の実施
- EU域内の代理人の設置（EU域外事業者の場合）

#### 汎用目的AIモデル（GPAI）への規制
- 本プロダクトがGPAIモデルを利用する場合、モデル提供者の義務（技術文書提出、著作権法遵守等）にも留意

### 1.4 違反時の制裁

| 違反の種類 | 最大制裁金 |
|---|---|
| 禁止AIシステムの提供 | 3,500万EUR または全世界売上の7% |
| 高リスクAI義務違反 | 1,500万EUR または全世界売上の3% |
| 不正確な情報提供 | 750万EUR または全世界売上の1% |

### 1.5 推奨アクション

1. プロダクトの用途を明確にし、リスク分類を確定する
2. 教育・雇用分野向けに提供する場合は「高リスク」前提で準備
3. 技術文書（Technical Documentation）のテンプレートを早期に準備
4. EU域内の法的代理人の選定を検討

## 2. 日本のAI関連法制度

### 2.1 現行の関連法令

日本には2026年5月時点でAI単独の包括的規制法はないが、以下の既存法令が適用される。

| 法令 | 関連事項 |
|---|---|
| 個人情報保護法 | 判定対象データに含まれる個人情報の取扱い |
| 著作権法（30条の4） | 情報解析目的でのデータ利用の権利制限 |
| 不正競争防止法 | 競合サービスのデータを大量に判定する行為 |
| 消費者契約法 | BtoC向け利用規約における免責条項の制限 |
| 電気通信事業法 | 通信の秘密、利用者情報の取扱い |
| プロバイダ責任制限法 | 判定結果に基づく名誉毀損の媒介責任 |

### 2.2 政府ガイドライン

| ガイドライン | 発行元 | 主な内容 |
|---|---|---|
| AI事業者ガイドライン | 総務省・経済産業省 | AI開発・利用における10原則（透明性、公平性、安全性等） |
| AI利活用ガイドライン | 総務省 | AI利用者が留意すべき事項 |
| 広島AIプロセス成果文書 | G7 | 高度AIシステムの国際指針 |

### 2.3 今後の法整備動向

- AI基本法（仮称）の制定議論が進行中
- EU AI Actの域外適用を受ける可能性（EU居住者向けサービス提供時）
- 業界別のAI利用ガイドライン整備の加速（特に教育・金融分野）

### 2.4 推奨アクション

1. AI事業者ガイドラインの10原則への適合性を確認
2. 著作権法30条の4の適用範囲について法的見解を取得
3. 個人情報保護委員会のAI関連ガイダンスを継続的にモニタリング
4. 業界団体への参加による情報収集

## 3. 米国のAI関連規制

### 3.1 連邦レベル

| 法令・大統領令 | 内容 |
|---|---|
| AI権利章典のための青写真 (2022) | 拘束力はないが政策方向性を示す |
| 大統領令14110号 (2023) | 安全で信頼できるAIの開発・利用に関する指針 |
| FTC法 第5条 | 不公正・欺瞞的なAI利用への法執行根拠 |
| FERPA | 教育記録の保護（教育機関向け提供時） |
| COPPA | 13歳未満の児童データ保護 |

### 3.2 州レベル（主要州）

| 州 | 規制内容 |
|---|---|
| コロラド州 | AI消費者保護法（2024成立、高リスクAIの影響評価義務） |
| カリフォルニア州 | CCPA/CPRAによるデータ保護、自動意思決定に関する権利 |
| イリノイ州 | AIビデオ面接法（採用分野でのAI利用規制） |
| ニューヨーク市 | 自動雇用意思決定ツール法（雇用分野でのAI監査義務） |

### 3.3 推奨アクション

1. 教育機関向け提供時はFERPA・COPPA対応を最優先
2. 米国ユーザーへの提供時は主要州法への対応を検討
3. FTCの法執行動向を継続的にモニタリング

## 4. その他主要国・地域の規制

### 4.1 英国

- AI白書に基づく原則ベースのアプローチ（セクター別規制）
- ICO（情報コミッショナー）によるAIとデータ保護ガイダンス
- UK GDPR の適用

### 4.2 中国

- 生成AIサービス管理暫定弁法（2023年施行）
- ディープシンセシス規制（ディープフェイク規制を含む）
- アルゴリズム推薦管理規定
- 注意: AI生成物判定はディープシンセシス規制と密接に関連

### 4.3 韓国

- AI基本法（2025年施行）による高リスクAIの規制
- 個人情報保護法によるデータ保護

### 4.4 カナダ

- AIDA（Artificial Intelligence and Data Act）法案
- PIPEDA によるデータ保護

### 4.5 ブラジル

- AI規制法案（審議中）
- LGPD（一般データ保護法）によるデータ保護

## 6. 規制対応ロードマップ

### Phase 1: 国内ローンチ前（必須）
- [ ] 個人情報保護法への適合確認
- [ ] AI事業者ガイドライン適合性チェック
- [ ] 著作権法30条の4の適用整理
- [ ] 利用規約・プライバシーポリシーの日本法準拠版作成

- [ ] EU AI Actのリスク分類確定
- [ ] 技術文書の作成

### Phase 3: 米国展開準備

### Phase 4: その他地域展開
- [ ] 対象国の規制調査
- [ ] ローカライゼーション（法的文書の現地法対応）

## 7. 継続的モニタリング体制

AI規制は世界的に急速に変化しているため、以下のモニタリング体制を推奨する:

1. **四半期ごと**: 主要国のAI規制動向レビュー
2. **月次**: EU AI Act関連の施行細則・ガイダンスの確認
3. **随時**: 日本政府のAI関連ガイドライン改定の追跡
4. **外部専門家**: AI規制に精通した法律事務所との顧問契約

---

*本文書は規制動向の概要を示すものであり、法的助言を構成するものではありません。各国展開時には、現地法域の資格を持つ弁護士への相談が必須です。規制状況は急速に変化するため、定期的な見直しが必要です。*
