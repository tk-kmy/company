# AI生成物判定プロダクト - 収益モデルの選択肢

作成日: 2026-05-05
作成部署: 法務・経理部

## 1. 収益モデル比較一覧

| モデル | 初期導入障壁 | 収益安定性 | スケーラビリティ | 推奨ターゲット |
|---|---|---|---|---|
| SaaS（月額/年額課金） | 低〜中 | **高** | 高 | 教育機関、出版社、企業 |
| API従量課金 | 低 | 中 | **極めて高** | 開発者、プラットフォーム事業者 |
| フリーミアム | **極めて低** | 低〜中 | 高 | 個人、小規模事業者 |
| エンタープライズライセンス | 高 | **極めて高** | 低 | 大企業、政府機関 |
| ホワイトラベル/OEM | 高 | 高 | 中 | プラットフォーム事業者 |

## 2. 各モデルの詳細分析

### 2.1 SaaS型（月額/年額サブスクリプション）

#### プラン設計案

| プラン | 月額(税抜) | 年額(税抜) | 主な機能 | 想定ターゲット |
|---|---|---|---|---|
| Starter | 5,000円 | 50,000円 | 月500回判定、テキストのみ、基本レポート | 個人・フリーランス |
| Professional | 30,000円 | 300,000円 | 月5,000回判定、テキスト+画像、詳細レポート、API連携 | 中小企業、教育機関 |
| Business | 100,000円 | 1,000,000円 | 月50,000回判定、全メディア対応、バッチ処理、管理ダッシュボード、SLA保証 | 大企業、出版社 |
| Enterprise | 個別見積 | 個別見積 | 無制限判定、オンプレミス/VPC対応、専用サポート、カスタム統合 | 大企業、政府 |

#### メリット
- 収益の予測可能性が高い（MRR/ARRが安定）
- 顧客のLTV（顧客生涯価値）を最大化しやすい
- 投資家からの評価が高い（SaaSメトリクスが適用可能）

#### デメリット
- 解約率（チャーン）の管理が重要
- 機能の継続的な改善が求められる
- 価格変更が既存顧客に影響を与える

#### 財務指標の目安
- 目標チャーンレート: 月次 3%以下（年次 30%以下）
- 目標LTV/CAC比: 3倍以上
- 年額プラン比率: 40%以上を目指す（キャッシュフロー改善）

---

### 2.2 API従量課金

#### 価格設計案

| 項目 | 単価 | 備考 |
|---|---|---|
| テキスト判定（1,000文字以下） | 5円/回 | 基本単価 |
| テキスト判定（1,000文字超） | 5円 + 3円/1,000文字 | 長文加算 |
| 画像判定 | 15円/回 | 1枚あたり |
| コード判定 | 10円/回 | 1ファイルあたり |
| バッチ判定（100件以上） | 基本単価の80% | ボリュームディスカウント |
| 月間10万回以上 | 基本単価の60% | 大口顧客向け |

#### ボリュームディスカウント体系

| 月間リクエスト数 | 割引率 |
|---|---|
| 〜10,000 | 0%（基本単価） |
| 10,001〜100,000 | 10% |
| 100,001〜1,000,000 | 20% |
| 1,000,001〜 | 40%（個別交渉） |

#### メリット
- 利用量に応じた公平な課金で導入障壁が低い
- 大規模利用時にスケールメリットを享受できる
- 開発者コミュニティへの訴求力が高い

#### デメリット
- 収益の変動が大きい（季節性、利用パターン依存）
- 無料枠・低単価の場合、収益化に時間がかかる
- インフラコストとの連動管理が必要

---

### 2.3 フリーミアム

#### 設計案

| 区分 | 内容 |
|---|---|
| **無料プラン** | 月50回判定、テキストのみ、基本判定（AI/非AIの二値）、ウォーターマーク付きレポート |
| **有料プラン** | 上記SaaSプランに移行 |

#### コンバージョン戦略

| 段階 | 施策 |
|---|---|
| 認知 | 無料プランによる利用者獲得、SEO、コンテンツマーケティング |
| 活性化 | 詳細分析レポートのプレビュー表示、判定回数上限到達時のアップグレード誘導 |
| 収益化 | API連携、チーム管理、バッチ処理等の有料機能 |
| 紹介 | 紹介プログラム（紹介者・被紹介者に追加判定回数付与） |

#### メリット
- 市場浸透速度が速い
- ユーザーベースの構築が早く、ネットワーク効果を活用できる
- 口コミによる自然成長が期待できる

#### デメリット
- 無料ユーザーのインフラコストが発生（サーバー費用の負担）
- 有料転換率（コンバージョン率）は一般的に2〜5%と低い
- 無料プランの機能バランスが難しい（多すぎると課金されない、少なすぎると離脱）

#### 目標指標
- 月間無料ユーザー数: 10,000人以上（ローンチ6か月後）
- 有料転換率: 3〜5%
- 有料ARPU: 月額20,000〜50,000円

---

### 2.4 エンタープライズライセンス

#### 提供形態

| 形態 | 内容 | 価格帯(年額) |
|---|---|---|
| クラウド専用テナント | 顧客専用のクラウド環境で稼働 | 500〜2,000万円 |
| VPC内デプロイ | 顧客のVPC内にデプロイ | 800〜3,000万円 |
| オンプレミス | 顧客のサーバーにインストール | 1,000〜5,000万円 |

#### 付加サービス

| サービス | 内容 | 価格帯 |
|---|---|---|
| 導入支援 | システム統合、データ移行、トレーニング | 200〜500万円（一括） |
| カスタマイズ | 業界特化モデルの構築、UIカスタマイズ | 300〜1,000万円 |
| 専用サポート | 専任担当者、24/7サポート、SLA保証 | 月額30〜100万円 |

#### メリット
- 高い単価（ACV: 年間契約額が大きい）
- 長期契約が多く、収益の安定性が高い
- 顧客の要件に合わせた付加価値提供が可能

#### デメリット
- 営業サイクルが長い（3〜12か月）
- カスタマイズ対応の工数が大きい
- 少数顧客への依存リスク

---

### 2.5 ホワイトラベル / OEM提供

#### 概要

他社のプラットフォームやサービスに、当社の判定エンジンを組み込んで提供する形態。

#### 価格設計案

| 項目 | 価格帯 | 備考 |
|---|---|---|
| 初期統合費用 | 300〜800万円 | API統合、カスタマイズ |
| 月額基本料 | 50〜200万円 | 最低保証額 |
| 従量課金 | 2〜4円/判定 | 基本料を超える利用分 |
| レベニューシェア | 売上の15〜30% | 従量課金の代替 |

#### メリット
- 自社での販売・マーケティングコストを抑制できる
- パートナーの既存顧客基盤にアクセスできる
- 複数パートナーで収益源を分散できる

#### デメリット
- ブランド認知が構築しにくい
- パートナーへの依存度が高い
- 価格交渉力が弱くなる可能性

## 3. 推奨収益モデル戦略

### 3.1 フェーズ別戦略

| フェーズ | 期間 | 主力モデル | 補助モデル | 目標 |
|---|---|---|---|---|
| Phase 1: 市場参入 | 0〜6か月 | フリーミアム | API従量課金 | ユーザー獲得、PMF検証 |
| Phase 2: 収益化 | 6〜18か月 | SaaS月額/年額 | API従量課金 | MRR 500万円達成 |
| Phase 3: 拡大 | 18〜36か月 | SaaS + エンタープライズ | API + OEM | ARR 1億円達成 |
| Phase 4: グローバル | 36か月〜 | 全モデル併用 | | ARR 5億円達成 |

### 3.2 推奨ハイブリッドモデル

最もバランスの取れた収益構造として、以下のハイブリッドモデルを推奨する:

```
収益構成の目標比率（Phase 3時点）:

  SaaS サブスクリプション  : 50%（安定収益の柱）
  API 従量課金            : 25%（スケーラブルな収益）
  エンタープライズ        : 20%（高単価・長期契約）
  OEM / ホワイトラベル    : 5% （追加収益源）
```

## 4. 価格設定時の法的留意点

### 4.1 消費税・間接税
- 日本国内: 消費税10%の適用（BtoC向けは総額表示義務）
- 海外顧客: リバースチャージ方式、電気通信利用役務の提供に該当するか確認
- EU: VAT対応（顧客所在地の税率適用、OSS制度の利用検討）

### 4.2 景品表示法
- 「AI判定精度99%」等の表記には合理的根拠が必要
- 無料プランの広告表示は景品表示法の不当表示に該当しないよう注意
- 比較広告（競合との精度比較等）は客観的データに基づくこと

### 4.3 特定商取引法
- BtoC向け: 特定商取引法に基づく表記が必要
- サブスクリプションの解約・返金ポリシーの明示
- 無料トライアル→自動課金の場合の適切な告知

### 4.4 独占禁止法
- 市場支配的地位を獲得した場合の価格設定に注意
- 不当廉売（市場占有のための過度な低価格）の回避
- 抱き合わせ販売の規制への留意

### 4.5 インボイス制度対応
- 適格請求書発行事業者としての登録
- インボイスの要件を満たす請求書・領収書の発行

## 6. 損益分岐点分析

### 前提条件（標準シナリオ）
- 初期投資: 約2億円（開発費+初年度運用費）
- 月間固定費: 約800万円（運用費）
- 変動費率: 売上の20%（インフラ従量費、決済手数料等）
- 粗利率: 80%

### 損益分岐点

| 指標 | 値 |
|---|---|
| 月間損益分岐売上 | 1,000万円 |
| 必要有料ユーザー数（ARPU 5万円の場合） | 200ユーザー |
| 初期投資回収期間 | 18〜24か月 |
| 3年間累計営業利益（標準シナリオ） | 約7,000万円 |
