## 3. 差別化ポイント（5つの柱）

### 柱1: 日本語ネイティブ精度

| 当社 | 競合 |
|------|------|
| 日本語テキストに最適化した検出モデル | 英語モデルの翻訳・転用が多い |
| 日本語特有の文体・表現パターンを学習 | 日本語での精度が大幅に低下 |
| 敬語・ビジネス文書・学術文書への対応 | ビジネス日本語の文脈理解が弱い |

**根拠**: 既存の主要ツール（GPTZero、Turnitin、Originality.AI）はいずれも英語を主軸に開発されており、日本語テキストの判定精度は公式にはベンチマークされていない。日本語特化のKeiganAI（NABLAS）もディープフェイク検出が中心であり、テキスト判定のカバレッジは限定的。

### 柱2: マルチモーダル統合判定

| 当社 | 競合 |
|------|------|
| テキスト+画像+動画+音声を1プラットフォームで | 多くがテキストのみ |
| 統合ダッシュボードで一元管理 | モダリティごとに別ツールが必要 |
| クロスモーダル分析（テキストと画像の整合性チェック等） | クロスモーダル分析機能なし |

**根拠**: テキスト検出ツール（GPTZero、Originality.AI等）とディープフェイク検出ツール（Reality Defender、Hive AI等）は別市場として存在しており、統合ソリューションは事実上存在しない。

### 柱3: 判定根拠の透明性（Explainable Detection）

| 当社 | 競合 |
|------|------|
| 「なぜAI生成と判断したか」を詳細レポートで提示 | スコア（%）のみの表示が多い |
| 判定根拠のビジュアル表示 | ブラックボックス的な判定 |
| 法的証拠としても活用可能な詳細ログ | 監査ログ機能が限定的 |

**根拠**: 多くの既存ツールが「AI生成確率: 85%」のようなスコアのみを提示。教育現場では「なぜ疑わしいのか」の説明なしに学生を糾弾できないという深刻な課題がある。

### 柱4: エンタープライズ対応

| 当社 | 競合 |
|------|------|
| SSO/SAML対応、ロールベースアクセス制御 | 個人向けUIが多い |
| 監査ログ、コンプライアンスレポート自動生成 | コンプライアンス機能が弱い |
| SLA保証、専用サポート | 個人向けサポートレベル |
| オンプレミス/VPC対応オプション | クラウドのみ |
| EU AI Act対応レポート機能 | 規制対応機能なし |

### 柱5: ワークフロー統合

| 当社 | 競合 |
|------|------|
| CMS連携（WordPress、Notion等） | 限定的な連携 |
| LMS連携（Moodle、Google Classroom等） | Turnitinは強いが他は弱い |
| ATS連携（採用管理システム） | なし |
| Slack/Teams通知連携 | なし |
| 柔軟なAPI/Webhook提供 | API提供は一部のみ |

## 4. ブランドメッセージ提案

### プロダクト名案

| 案 | コンセプト |
|----|-----------|
| **AuthentiQ**（オーセンティーク） | Authentic + IQ。真正性と知性を融合 |
| **VerifAI**（ベリファイ） | Verify + AI。AIを検証するAI |
| **TrueScope**（トゥルースコープ） | True + Scope。真実を見通す |
| **GenCheck**（ジェンチェック） | Generated + Check。AI生成をチェック |
| **Shinsho**（真証） | 日本語の「真実を証明する」。日本発を強調 |

### タグライン案

1. **「AIが書いたか、人が書いたか。答えはここに。」**
2. **「コンテンツの真正性を、テクノロジーで保証する」**
3. **「Trust, but verify. AI時代の信頼をつくる。」**
4. **「見えないAIを、可視化する」**

### バリュープロポジション（エレベーターピッチ）

> 生成AIの普及により、テキスト・画像・動画・音声のあらゆるコンテンツが
> 「人が作ったのか、AIが作ったのか」を見分けることが困難になっています。
>
> 当社プロダクトは、日本語に最適化されたマルチモーダルAI検出エンジンにより、
> テキストから動画まであらゆるコンテンツのAI生成判定を高精度に実現します。
>
> 判定根拠を透明に提示し、EU AI Actをはじめとする規制対応にも活用できる
> エンタープライズ品質の信頼性を備えています。
>
> メディア、教育、そしてすべてのビジネスの「信頼」を支えるプラットフォームです。

## 5. 価格戦略提案

### 推奨モデル: フリーミアム + 段階制サブスクリプション + 従量課金ハイブリッド

| プラン | 対象 | 月額（税抜） | 内容 |
|--------|------|-------------|------|
| **Free** | 個人・試用 | 無料 | 月100件まで、テキストのみ |
| **Starter** | 小規模チーム | 9,800円 | 月1,000件、テキスト+画像 |
| **Professional** | メディア・教育 | 49,800円 | 月10,000件、マルチモーダル、API |
| **Enterprise** | 大企業 | 個別見積 | 無制限、オンプレ対応、SLA保証 |

### 従量課金オプション
- 超過分: テキスト判定 10円/件、画像判定 30円/件、動画判定 100円/分

### 価格の根拠
- Originality.AIのクレジット制（$30で3,000スキャン = 約1円/件）より高単価だが、日本語精度とマルチモーダル対応で正当化
- Turnitinの機関ライセンス（年間数百万円〜）との価格競争力を確保
- B2B SaaSの2026年トレンドであるクレジットベース+ハイブリッドモデルを採用
