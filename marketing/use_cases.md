## ユースケース詳細

### UC-1: メディア・出版社の原稿検収

**シナリオ**:
大手Webメディア「テクノロジーニュース社」は、月間500本以上の記事を外部ライター100名に発注している。2025年後半から、納品される記事のAI生成率が急増。読者からの信頼低下やSEOペナルティを懸念し、全原稿のスクリーニング体制を構築したい。

**ワークフロー**:
```
ライターが原稿を提出
    ↓
CMSに原稿がアップロードされる（WordPress連携）
    ↓
自動でAI判定APIが起動
    ↓
判定結果がダッシュボードに表示
    ├─ AI生成率 30%未満 → 通常の編集フローへ
    ├─ AI生成率 30〜70% → 編集者にアラート、詳細レビュー
    └─ AI生成率 70%以上 → ライターに差し戻し、理由を添付
    ↓
判定レポートを自動保存（監査ログ）
```

**導入効果**:
- 編集者の目視チェック工数を80%削減
- AI生成率の高い原稿の早期発見により品質維持
- ライターへの客観的フィードバックが可能に

### UC-2: 大学のレポート・論文チェック

**シナリオ**:
国立大学法人A大学では、学生のレポート提出にMoodleを利用。ChatGPT等を活用したレポートの増加により、学術的誠実性の担保が喫緊の課題に。既存ツール（Turnitin）では日本語のAI生成判定精度が不十分。

**ワークフロー**:
```
学生がMoodleでレポート提出
    ↓
LMS連携でAI判定が自動実行
    ↓
教員用ダッシュボードに結果表示
    ├─ AI生成の疑い低 → 通常採点
    ├─ AI生成の疑い中 → 該当箇所をハイライト表示、教員が確認
    └─ AI生成の疑い高 → 面談推奨アラート
    ↓
学期末にクラス全体の傾向レポートを自動生成
```

**導入効果**:
- 日本語レポートのAI生成判定精度が90%以上に向上
- 教員の確認作業が効率化（1レポートあたり3分→30秒）
- 学生へのAI利用ガイダンスの根拠データ提供
- 大学のアカデミックインテグリティポリシーの実効性確保

### UC-3: 企業のAIガバナンス・コンプライアンス

**シナリオ**:
日本の大手製造業B社（従業員5,000名、EU向け輸出あり）は、EU AI Act（2026年8月適用開始）への対応として、社内で生成AIが利用されている実態の把握と、外部公開コンテンツのAI生成管理体制を構築する必要がある。

**ワークフロー**:
```
社内ドキュメント・外部公開コンテンツの定期監査
    ↓
対象ファイルをバッチアップロード / API連携
    ↓
テキスト・画像・動画のAI生成判定を一括実行
    ↓
コンプライアンスレポート自動生成
    ├─ 部署別AI利用状況サマリー
    ├─ EU AI Act対応チェックリスト
    ├─ リスク評価スコア
    └─ 是正アクション推奨事項
    ↓
GRCツール（ServiceNow等）へレポート連携
```

**導入効果**:
- EU AI Act適用前の態勢整備を効率的に実現
- 「シャドーAI」の可視化と適切な利用促進
- 監査法人への説明資料の自動生成
- 年間コンプライアンスコスト30%削減（手動監査比）

### UC-4: 採用選考でのAI利用検知

**シナリオ**:
人材紹介大手C社は、年間10万件以上のエントリーシート・職務経歴書を処理。候補者がChatGPT等でES全体を生成するケースが増加し、面接との乖離が問題に。スクリーニング段階でAI生成を検知し、面接時の深堀りポイントとして活用したい。

**ワークフロー**:
```
候補者がESを提出（ATS経由）
    ↓
ATS連携でAI判定を自動実行
    ↓
候補者プロファイルにAI判定タグを付与
    ├─ AI利用なし → 通常選考
    ├─ 部分的にAI利用 → 該当箇所を面接官に共有
    └─ 大部分がAI生成 → 追加設問の自動送付
    ↓
面接官用の「確認ポイントシート」を自動生成
```

**導入効果**:
- ESスクリーニングの精度向上
- 面接の質の向上（AI生成箇所を深堀り）
- 採用コストの最適化（ミスマッチ低減）

### UC-5: 広告・クリエイティブの品質保証

**シナリオ**:
広告代理店D社は、クライアントから「人間のクリエイターが制作したコンテンツ」を要求されるケースが増加。外注パートナーからの納品物がAI生成ではないことを客観的に証明する手段が必要。

**ワークフロー**:
```
外注パートナーがクリエイティブを納品
    ↓
テキスト（コピー）+ 画像（ビジュアル）を一括判定
    ↓
「人間制作証明書」を自動生成
    ├─ AI生成率
    ├─ 判定根拠の概要
    └─ 判定日時・判定バージョン
    ↓
クライアントへの納品時に証明書を添付
```

**導入効果**:
- クライアントへの品質保証の客観的根拠
- 外注パートナーとの契約遵守の確認
- ブランドの信頼性維持

### UC-6: ジャーナリズムのファクトチェック支援

**シナリオ**:
通信社E社では、SNS上で拡散される情報のファクトチェック業務が急増。特にディープフェイク画像・動画の真贋判定が緊急課題。選挙期間中などに偽情報が拡散するリスクへの対応が必要。

**ワークフロー**:
```
疑わしいコンテンツ（画像・動画・テキスト）を検証デスクが受領
    ↓
マルチモーダル判定を実行
    ├─ 画像: AI生成/加工判定 + メタデータ分析
    ├─ 動画: ディープフェイク判定 + フレーム分析
    └─ テキスト: AI生成判定 + ソース照合
    ↓
判定レポートを記者・デスクに提供
    ↓
ファクトチェック記事の根拠資料として活用
```

**導入効果**:
- ファクトチェックの速度と精度の向上
- 選挙・災害時の偽情報対策の強化
- 報道の信頼性担保

## MVP（最小実用プロダクト）で実装すべきユースケース

### 推奨: UC-1（メディア原稿検収）+ UC-2（大学レポートチェック）

**理由**:
1. ペインが最も大きく、購買意欲が明確
2. テキスト判定が中心で、技術的にMVPとして実現可能
3. 日本語特化の差別化が最も効くセグメント
4. ケーススタディとして分かりやすく、他セグメントへの展開材料になる
5. 教育機関での採用実績は信頼性の証明として強力

### MVP必須機能
- 日本語テキストのAI生成判定（高精度）
- 判定根拠のハイライト表示
- ダッシュボード（判定履歴、統計）
- API提供（基本）
- CSV/PDFレポート出力
